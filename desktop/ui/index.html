Connect this computer to your workspace.

The address you use in the browser. It must be https — your session cookie travels over it.

In the browser, sign in and open Settings → Devices, then choose “Pair a computer”. The code lasts ten minutes.

Connecting to a computer on this network for the first time? It needs to trust that computer's security certificate before it will connect at all — on the other computer, open Settings → Network and follow “Connect a new computer” first.

Pairing records this computer so an administrator can see it and revoke it. You still sign in as normal, and nothing is stored on this machine except the workspace address.
